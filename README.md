# Записная книжка
Самостоятельная работа по основам серверной веб-разработки. Доненко Татьяна Александровна, группа 253-325.

## Опубликованный сайт
https://tania-feedback.rf.gd/contacts/index.php

На хостинге MySQL подтверждены просмотр, добавление, сохранение изменений и удаление контакта.

## Устройство
Единственная входная PHP-страница — `index.php`. Все внутренние переходы используют `index.php?action=...`.
- `menu.php`: `menu()` без параметров возвращает HTML меню. Основные кнопки синие, активные красные. При просмотре отображаются меньшие кнопки сортировки.
- `viewer.php`: `viewer(string $sort, int $page)` возвращает HTML таблицы и пагинации. Не более 10 контактов на странице. Сортировки: добавление, фамилия, дата рождения по возрастанию. Неуказанные даты выводятся в конце. При равных фамилиях записи сортируются по имени, затем id.
- `add.php`: обработка добавления и статическая HTML-форма; зелёное сообщение «Запись добавлена», красное «Ошибка: запись не добавлена».
- `edit.php`: список фамилий и имён, выбранный контакт и форма. По умолчанию выбирается первый контакт. Ошибочный POST никогда не изменяет другую запись.
- `delete.php`: ссылки с фамилией и инициалами, удаление и сообщение с фамилией. Удаление по GET-ссылке реализовано по условию задания; в ссылку добавлен токен сессии.
- `helpers.php`, `config.php`: подключение PDO, валидация, экранирование, общие функции.
Прямой запрос любого PHP-модуля возвращает 403 (проверка константы + .htaccess для Apache). CSS и SVG доступны как ресурсы оформления.
После успешного изменения применяется перенаправление 303: обновление страницы не повторяет операцию.

## Локальный запуск
PHP 8.1+ с PDO, pdo_sqlite и mbstring. В папке проекта:
```sh
php -S 127.0.0.1:8081
```
Открыть http://127.0.0.1:8081/index.php. По умолчанию создаётся пустая SQLite-база в data/contacts.sqlite. Файлы SQLite не добавляются в Git. На хостинге используйте MySQL.

## Размещение в InfinityFree
1. Создайте базу MySQL в аккаунте хостинга. Скопируйте MySQL Hostname, Database Name и Username. Пароль — пароль MySQL/хостинг-аккаунта из его панели, который может отличаться от пароля входа в сайт InfinityFree.
2. В File Manager создайте папку `htdocs/contacts`. Предыдущий Feedback form в корне не изменяйте.
3. Загрузите туда PHP-файлы, .htaccess и папку assets с двумя файлами logo.svg и style.css.
4. Скопируйте `config.local.example.php` как `config.local.php`. Вставьте свои host, database, username, password. Сохраняйте одинарные кавычки; если пароль содержит апостроф или обратную косую черту, экранируйте их в строке PHP.
5. Откройте https://tania-feedback.rf.gd/contacts/index.php. Таблица создаётся автоматически. Если нет разрешения CREATE TABLE, импортируйте schema.sql через phpMyAdmin.
6. Для демонстрации пагинации можно однократно импортировать demo_contacts.sql в пустую таблицу через phpMyAdmin. В нём 23 вымышленных контакта; реальные данные не используются.
7. Проверьте добавление, редактирование, удаление, 3 сортировки и страницы 1–3. Не публикуйте config.local.php в GitHub.

## Проверки
Локальные интеграционные проверки выполнены на отдельной SQLite-базе: CRUD, валидация, сохранение выбранной записи, неправильный id, запрет удаления без токена, экранирование HTML, страницы по 10 записей, сортировки, пустая база, неправильные и массивные параметры URL, прямое открытие модулей. Работа с MySQL на хостинге подтверждена снимками пользователя в чате.

## Ограничения учебной работы
Авторизация пользователей не предусмотрена заданием. Любой посетитель опубликованного сайта может изменять общую книжку. Для демонстрации используйте только вымышленные контакты.
Ссылки Moodle на образцы form.php и style.css не удалось прочитать; форма реализована по текстовому условию. Сопоставить её с образцами можно после получения файлов.
